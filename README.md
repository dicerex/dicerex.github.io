# Александр Алексеев — портфолио

Одностраничное портфолио на Astro 7 и TypeScript. Русский и английский языки, адаптивная вёрстка, светлая и тёмная темы, фильтрация работ. Описания раскрываются внутри карточек, снимки увеличиваются в диалоге. Шрифты Manrope и JetBrains Mono включены в сборку и не требуют Google Fonts.

## Локальный запуск

Node.js 24 (версия указана в `.nvmrc`):

```sh
nvm use
npm ci
npm run dev
```

Открыть адрес, напечатанный Astro, обычно `http://127.0.0.1:4321`.

```sh
npm run build
npm run preview
```

Сборка запускает проверку типов, создаёт `dist/` и проверяет внутренние ссылки, ресурсы и пути публикации.

## GitHub Pages

Этот каталог `www` — корень Git-репозитория. Файлы из родительского каталога не нужны для установки, сборки и публикации.

1. Создать пустой репозиторий на GitHub без README и дополнительных файлов.
2. Из этого каталога подключить его и отправить ветку:

   ```sh
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main
   ```

3. В GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Дождаться workflow **Deploy portfolio to GitHub Pages**. Если первый запуск произошёл до настройки Pages, повторить его во вкладке Actions.

Workflow собирает `dist` и публикует только готовый сайт. Репозиторий не должен содержать внешнюю папку `www`: содержимое текущего каталога отправляется непосредственно в корень репозитория.

Адрес и базовый путь определяются через `GITHUB_REPOSITORY`. Поддерживаются и проектный адрес `USERNAME.github.io/REPOSITORY/`, и репозиторий `USERNAME.github.io` в корне домена. Для собственного домена можно задать Actions Variables `SITE_URL` и `BASE_PATH` (значение `/` для корня), а также добавить `public/CNAME`.

Локальная проверка проектного адреса:

```sh
GITHUB_REPOSITORY=example/portfolio npm run build
BASE_PATH=/portfolio/ npm run preview
```

## Содержимое и дизайн

- `src/data/projects.ts` — коммерческие кейсы, английские описания, галереи и отдельно личные проекты.
- `src/data/i18n.ts` — русские и английские тексты интерфейса и описание разработчика.
- `src/components/T.astro` — переключаемые тексты из доверенных, редактируемых в репозитории данных. Не передавать в этот компонент внешнее содержимое: он поддерживает HTML-разметку.
- `src/components/ProjectArt.astro` — обложки: реальный снимок или подписанная схема продукта.
- `src/components/ProjectCard.astro` — карточки с описанием и галереей, раскрываемые без смены страницы.
- `src/components/Lightbox.astro` — увеличение снимков, переключение стрелками, Escape и возврат фокуса.
- `src/styles/global.css` — адаптивная вёрстка и темы.
- `public/images/projects/<slug>/` — подготовленные публичные снимки.

Сайт содержит Amelia, Вратарницу, Сэйв, GodenDo (добавлен с разрешения владельца), Alean, UnitedMission и «Лёд и пламя». VPN-платформа, Crypto bot и Trade v2 обозначены как личные проекты. Не добавляйте результаты, метрики, сведения о личной роли и скриншоты без проверки с владельцем.

Для всех семи кейсов подключены реальные снимки. Если у будущего проекта снимков нет, обложка использует явно подписанную схему. Материалы заказчиков перед добавлением нужно обезличить. Исходное резюме и приватная инвентаризация не входят в репозиторий. Для Сэйв выбран экран входа: предоставленный снимок списка объектов с рабочими номерами и состояниями не скопирован в публичные файлы.

## Языки

RU/EN переключаются на той же странице без перезагрузки. Приоритет выбора: `?lang=ru` или `?lang=en` → сохранённый выбор → язык браузера (русский либо английский). Меняются тексты, подписи снимков, доступные имена кнопок, язык документа и метаданные. Без JavaScript доступна русская версия и стандартное раскрытие описаний.

## Добавление снимков

Положить готовый WebP/PNG в `public/images/projects/<slug>/` и дополнить `screenshots` нужного проекта:

```ts
screenshots: [{
  src: 'projects/amelia/02-product.webp',
  width: 562,
  height: 1280,
  alt: { ru: 'Карточка букета', en: 'Bouquet details' },
  caption: { ru: 'Выбор букета', en: 'Choosing a bouquet' },
}]
```

Первый снимок используется как обложка. Для портретного снимка автоматически используется оформление телефона, для горизонтального — браузера. Галерея поддерживает любое количество снимков; данные и подписи нужно добавлять для обоих языков. После добавления выполнить `npm run build`, чтобы проверить пути.

Предоставленные владельцем снимки используются для Amelia, Вратарницы, Сэйв и GodenDo. Alean и UnitedMission сняты с локальных копий интерфейсов без рабочих серверных обработчиков; исходные проекты не изменялись. Снимок «Лёд и пламя» получен из существующей статической сборки. Сборки для съёмки, промежуточные PNG и инструменты проверки находятся в игнорируемом `.local/`, в публикацию не входят.

## Статус

Это локальная версия портфолио с черновыми описаниями проектов на основе кода и предоставленных снимков. Публикация требует созданного владельцем GitHub-репозитория. Формулировки личного вклада и результаты проектов можно уточнить совместно с владельцем.
